# 项目背景与需求来源

> 脱敏处理，去除公司和团队信息。

## 一、行业背景

大模型团队正在寻找熟悉前后端工程和脚本语言的研发工程师，一起提升大模型在代码生成、复杂企业级软件开发，以及 Agent 框架构建中的能力。

这个方向横跨前端工程、后端服务、AI Coding、Agent Framework 和强化学习训练基础设施。需要构建真实软件工程任务、开发训练与评测环境、设计复杂企业级应用场景，并与模型训练、数据、评测团队协作，帮助模型更好地理解和生成高质量、可维护、可运行的工程代码。

## 二、核心需求

1. 设计和构建高质量前后端代码任务，用于提升模型的代码生成、代码修改、调试、重构和系统实现能力
2. 针对复杂企业级软件场景，沉淀真实工程任务（后台系统、数据看板、工作流平台、权限管理、表单系统、API 服务、业务中台、低代码/配置化平台等）
3. 参与代码评测体系建设，设计可自动验证的 benchmark、单元测试、接口测试、端到端测试、视觉回归测试和交互行为验证
4. 基于 JavaScript / TypeScript / Python 等脚本语言，参与 Agent 框架、工具调用框架、任务执行环境和强化学习训练环境的开发
5. 构建用于 RL 训练的 Agent 任务环境，包括任务定义、状态反馈、奖励设计、执行沙箱、工具链集成、前后端联调与自动化验证
6. 分析模型在前后端代码生成、复杂工程实现和 Agent 任务执行中的失败案例，归因问题并设计改进数据、训练任务或评测方法
7. 与模型训练、算法、产品和工程团队合作，将真实业务场景转化为可训练、可评测、可迭代的任务体系

## 三、能力要求

### 必须

1. 熟悉现代前后端开发，具备扎实的 JavaScript / TypeScript 或 Python 基础
2. 理解复杂软件工程的常见问题（组件设计、状态管理、路由、表单、权限、数据请求、API 设计、数据库交互、构建工具、测试和工程化）
3. 熟悉至少一种脚本语言，能够快速开发工具、自动化脚本、任务执行框架或评测环境
4. 具备良好的代码质量意识，重视可维护性、可测试性、可读性和工程规范
5. 对大模型代码生成、AI Agent、工具调用、自动化任务执行或强化学习训练有兴趣
6. 具备较强的问题拆解能力，能够把复杂软件开发任务转化为清晰的训练样本、评测标准或工程实现方案

### 加分

1. 有复杂企业级系统开发经验（SaaS、CRM、ERP、BI、低代码平台、流程引擎、数据分析平台、业务中台、开发者工具等）
2. 熟悉前后端测试体系（Jest、Vitest、Playwright、Cypress、Testing Library、Pytest 等）
3. 有 AI Coding、代码评测、自动化修复、代码智能体、IDE 插件或开发者工具相关经验
4. 熟悉 Agent 框架或工具调用系统（LangChain、AutoGen、OpenAI Agents SDK、CrewAI、MCP 等）
5. 有强化学习、RLHF、RLAIF、代码训练数据构建、benchmark 设计或模型评测经验
6. 熟悉浏览器自动化、沙箱执行、CI/CD、Docker、Node.js 工具链、Web 服务部署等基础设施
7. 有开源项目、技术博客、前后端框架/工具库贡献经验

## 四、我们的项目如何对标这些需求

| 需求 | 本项目对标 |
|------|-----------|
| Agent 框架开发 | `packages/core` — ReAct 循环、Tool Use、对话管理 |
| 工具调用框架 | `packages/tools` + `packages/mcp` — 可插拔工具 + MCP 兼容 |
| 代码评测体系 | `packages/eval` — 分级 Benchmark + 插件化评分 |
| 任务执行环境 | 评测沙箱（Docker 隔离 + 超时控制） |
| 失败案例归因 | Failure Analysis 模块（AI 自动归因 + 改进建议） |
| 真实工程任务 | `benchmarks/` — 从函数级到项目级的真实编码任务 |

## 五、项目设计理念

1. **开闭原则（插件化）**：核心稳定，能力通过插件扩展。Tool、Skill、Scorer、Validator 都是可插拔的，不改核心代码就能加新能力。
2. **模型无关**：不绑定任何一个 LLM，通过适配层接入任意 OpenAI 兼容模型。
3. **配置驱动**：行为通过配置文件控制（Steering/Skills/Benchmark），不硬编码。
4. **面向评测**：不只是一个 Agent 产品，也是一个评测平台——能系统化地衡量和对比不同模型的 Coding 能力。
5. **渐进式**：从最小可用开始，逐步加能力，不过度设计。
6. **面向训练**：评测结果不只是分数，还包括失败归因和改进建议，可直接反馈给模型训练团队。
7. **工程化标准**：项目本身就是高质量工程代码的示范——TypeScript 严格模式、完善的测试、CI/CD、文档齐全。

## 六、差异化价值

和市面上已有的 Agent 框架（LangChain/AutoGen/CrewAI）相比：

| 维度 | 已有框架 | 本项目 |
|------|---------|--------|
| 定位 | 通用 Agent 框架 | 专注 Coding Agent + 评测 |
| 评测 | 无内置 | 内置分级 Benchmark + 插件化评分 |
| 训练支持 | 无 | Failure Analysis + 改进建议，可直接用于模型训练 |
| 语言 | Python 为主 | TypeScript（前端生态友好） |
| 模型 | 通常绑定 OpenAI | 模型无关（支持任意 OpenAI 兼容接口） |
| 工具协议 | 各自定义 | MCP 兼容（业界标准） |
